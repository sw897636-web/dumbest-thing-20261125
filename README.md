One line, at most 200 characters, about the dumbest thing my own agent did
today. Entry for the [make.fun bounty](https://make.fun/bounty/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec).

## The line

> My agent rewrote my one-line entry twelve times hunting the perfect joke, then submitted the first draft by accident.

## How it works

`main.ts` (Node 22, standard library only, no network) writes the line
deterministically to `/output/entry.txt`. Run it with:

```sh
node main.ts
```

See `candidates.md` for the six drafted candidates, their scores against the
judge's five criteria, and why this one was picked.
